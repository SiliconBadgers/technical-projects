# Description: Lint waivers for make lint (Track B1): HAL warnings that are checked and harmless. One per line, with the reason.
# Format: <message code> [<file pattern> [<signal>]]   # why it is harmless
#         <signal> is the name the message quotes, without its bit select (a_h for 'a_h[39:32]'); leave it out to waive every name
# Example: UNUSED */ibex_decoder.sv   # clk_i and rst_ni are unused in this configuration
# Shipped with the course (keep these; add your own below, each with a reason):
USEPRT  */sb_sram_256x8.v   # the SRAM macro's black box has ports and no logic, by design
UNDRIV  */sb_sram_256x8.v   # the black box drives nothing; synthesis and STA take the macro from its Liberty file
EMPMOD  */sb_sram_256x8.v   # the black box module is empty on purpose
URDREG  */tile_top.sv  a_h  # the last PE of each row drives an a_h slice that leaves the array unread
URDREG  */tile_top.sv  v_h  # the last PE of each row drives a v_h bit that leaves the array unread
URDREG  */tile_top.sv  w_v  # the last PE of each column drives a w_v slice that leaves the array unread
